# chuck-chuck-chuck-net.github.io

The index page at <https://chuck-chuck-chuck-net.github.io>, linking out to the
project sites.

Each project publishes its own site from a `gh-pages` branch in its own
repository, under its own subdomain — slaptain at
<https://slaptain.chuck-chuck-chuck.net> — so a page travels with the repo it
describes, including across an organization move.

**This repo holds published bytes only.** Everything in it is on the internet.
Project pages, and the talk deck, do not belong here; see the `gh-pages` branch
of the project in question.
